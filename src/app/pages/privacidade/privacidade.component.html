LGPD & PRIVACIDADE

Política de Privacidade

O ReliefFlow foi desenvolvido como projeto acadêmico. Nesta demonstração, os dados são armazenados apenas no navegador do usuário por meio de localStorage.

Dados tratados

Nome, e-mail, credenciais simuladas, publicações e consentimento de privacidade podem ser armazenados localmente para demonstrar as funcionalidades do sistema.

Finalidade

Os dados são utilizados exclusivamente para autenticação simulada, personalização da experiência e demonstração das funcionalidades do projeto.

Direitos do titular

O usuário pode consultar seus dados no perfil e utilizar a opção de exportação. Em uma aplicação real, seriam implementados mecanismos seguros de correção, portabilidade e exclusão.

Importante

Este protótipo não deve armazenar dados pessoais reais ou sensíveis. Uma versão de produção exigiria backend, autenticação segura, banco de dados e controles adicionais de segurança.
